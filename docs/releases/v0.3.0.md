BlackForge generates OBEOS-style project scaffolds from templates and validates OBEOS components against a manifest contract.

**Pre-release.** First tagged release of a working project. An engineering tool for demonstration and controlled local use.

### What it does
- `blackforge list-templates`, `new` / `create` (with `--preview`) for cli, fastapi and several `obeos-*` templates.
- Component inspection and validation against the OBEOS manifest contract.
- A contract evaluation suite under `eval/`.
- Path-traversal and overwrite protection when generating projects.

### Verified
- 45 automated tests pass in CI.
- The wheel installs in a clean environment and the `blackforge` command runs.

### Known limits
- Templates are starting points, not maintained frameworks.
- Only the Python 3.11 and 3.12 CI matrix has been run.
- Not tested on Windows or macOS by hand.

Checksums are in `SHA256SUMS`. See the [changelog](https://github.com/5K-bit/Blackforge/blob/v0.3.0/CHANGELOG.md) for details.
